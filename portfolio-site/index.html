§ 03Projects

Three projects, end to end.

01Personal project · In active development

F1 AI

An agentic race engineer that shows its sources.

Ask about a race, a strategy call or a regulation, and F1 AI answers like an engineer on the pit wall. A custom agent loop runs 16 specialized tools (race analysis, lap-telemetry comparison, strategy and ML race predictions) on DeepSeek-V4-Flash, with automatic failover to Gemini and a checker that verifies the driver and team claims in every answer.

Answers are grounded in FIA regulations and more than 75 years of race records through Supabase pgvector retrieval, cross-encoder reranking and constrained text-to-SQL. The agent’s progress streams to the browser while it works, 10 analysis tools are exposed to Claude Desktop and Cursor through the Model Context Protocol, and a weekly CI job retrains the scikit-learn race predictor and ships new versions through auto-merged pull requests.

I design, direct and ship F1 AI, with AI coding agents doing the implementation.

02

Arizona State University · Team project

WeVibe

An iOS dating app, from sign-in to first message.

A SwiftUI iOS app with a Node.js, Express and TypeScript backend, built by a student team. I built the iOS flows for sign-in, onboarding, profiles, photos, location, matchmaking and chat, and extended the backend for photo uploads, location sync, push notifications and message pagination.

On the real-time side, I built the app’s Socket.IO layer: a centralized chat store with unread badges, typing indicators in the chat list and re-sync when the app returns to the foreground. I also added Firebase Cloud Messaging, Apple Sign-In with token revocation on account deletion, and cooldowns and daily rate limits for the team’s Gemini-powered bio generator.

03

Arizona State University · Solo project

Gotham Watch

Crime analysis, asked of a knowledge graph.

An interactive crime analysis platform over FBI county-level crime data (2011–2014): React data visualizations, powered by Python and Flask APIs running SPARQL queries over a GraphDB knowledge graph hosted on Microsoft Azure.

I built it end to end on my own: cleaning the FBI and FIPS data in pandas, mapping it onto an OWL ontology as about 400,000 RDF triples, hosting GraphDB on Azure, and writing the Flask API and the React UI.

React · Python · Flask · SPARQL · GraphDB · Azure
